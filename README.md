# NeurIPS 2026 Education Track — event website

Static single-page site for the Education Track at NeurIPS 2026 (Sydney).

## Structure

- `index.html` — the page (hero, about, submitter/attendee cards, schedule timeline, open-repository CTA, footer)
- `styles.css` — all styling (responsive, mobile nav)
- `script.js` — mobile nav toggle
